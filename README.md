# Wordle

**«Wordle»** — это логическая словесная игра, в которой игрок
должен угадать слово из **N** букв за **6** попыток.

## Цель проекта

Составить программу, позволяющую играть в «Wordle»:
* игроку с компьютером
* двум игрокам
  
## Назначение
Учебный проект в рамках лабораторной работы по дисциплине програмная инженерия по изучению
платформы GitHub и языка разметки Markdown.

## Режимы игры
### Игрок с компьютером
Компьютер загадывает слово, а игрок пытается его отгадать.
### Игрок с игроком
Один игрок загадывают слово, а другой пытается отгадать его. Потом игроки меняются местами. Побеждает тот, кто справится за меньшее количество попыток.



## Правила игры
1. Дано загаданное слово из N букв (существительное в именительном падеже).
2. Игрок вводит слова из N букв, пытаясь угадать загаданное.
3. После каждой попытки буквы подсвечиваются:
   - **Зелёный** — буква есть в слове и стоит **на своём месте**.
   - **Жёлтый** — буква есть в слове, но **не на своём месте**.
   - **Серый** — буквы **нет** в загаданном слове.
4. У игрока есть **6 попыток**.
5. Победа — если слово угадано. Поражение — если попытки закончились.

## Пример
Загаданное слово: Повар
